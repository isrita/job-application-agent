# Changelog

## 1.0.0 — 2026-10-04

Foundation release for human-assisted sports arbitrage monitoring and paper signals.

- Validated offline coordinator/specialist blueprint with conditional review and data-quality routes.
- Proposed Bronze/Silver/Gold schema with evidence lineage and append-only Bronze records.
- Manual read-only Predictefy catalog adapter and isolated Kalshi reference application.
- English architecture documentation, flow image, scaffolding, and offline CI.
- 22 Python and 40 reference tests.

Sports adapters, LangGraph runtime, deployed databases, and sports evaluation are pending. No automated sports orders are enabled. The isolated reference retains its separate 0.1.0 package version.
