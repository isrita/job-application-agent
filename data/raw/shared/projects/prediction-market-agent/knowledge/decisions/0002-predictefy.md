# Decision 0002: Predictefy onboarding

Predictefy was selected for an initial normalized catalog integration. The Python
SDK is pinned to 1.0.0b8 and one manual read-only catalog request is implemented.
Catalog authentication succeeded on October 3, 2026. This does not establish
sports book access, rule equivalence, latency classification, or signal quality.

Credentials remain local and excluded from documentation and model context.
Future sports adapters require explicit capability verification and evidence.
