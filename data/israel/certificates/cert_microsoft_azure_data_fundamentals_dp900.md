# Microsoft Certified: Azure Data Fundamentals (DP-900)

Validates foundational mastery of core cloud data concepts, relational and non-relational storage patterns, transactional vs. analytical workloads, and end-to-end data processing across Microsoft Azure data services.

## Key Competencies
- **Core Cloud Data Concepts:** Relational database paradigms, ACID properties, non-relational document/graph stores, and streaming vs. batch architectures.
- **Relational Data on Azure:** Azure SQL Database, Azure SQL Managed Instance, and PostgreSQL/MySQL hyperscale configurations.
- **Non-Relational Storage:** Azure Cosmos DB APIs, multi-model storage, partition strategies, and Azure Blob / ADLS Gen2 object storage.
- **Modern Analytics Architecture:** Azure Synapse Analytics, Azure Data Factory ETL/ELT orchestration, and business intelligence reporting.
