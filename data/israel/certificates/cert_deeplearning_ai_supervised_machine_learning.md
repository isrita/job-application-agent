# Supervised Machine Learning: Regression and Classification

Issued by DeepLearning.AI and Stanford Online, authorized by Andrew Ng. Validates core theoretical foundations and practical hands-on implementation of supervised machine learning algorithms using Python and NumPy.

## Key Competencies
- **Linear & Logistic Regression:** Mathematical formulation, cost functions (MSE, Binary Cross-Entropy), and optimization via gradient descent.
- **Feature Engineering & Preprocessing:** Polynomial features, feature scaling, normalization, and handling feature collinearity.
- **Regularization & Generalization:** Addressing overfitting and underfitting using L1 (Lasso) and L2 (Ridge) regularization parameters.
- **Model Evaluation & Diagnostics:** Precision, recall, F1-score, cross-validation metrics, and decision boundary calibration.
